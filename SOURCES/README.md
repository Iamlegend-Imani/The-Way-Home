# Sources

The Sources section exists so readers can distinguish where ideas come from and verify what can be verified.

## Source preservation workflow

The Way Home now uses four layers:

**Raw notes → private source archive → edited Library resource → public website**

Raw notes are preserved before editorial restructuring. They are not automatically published in this public repository. This keeps the original teaching available for comparison without turning every private note, transcript, or unfinished idea into public material.

## Source Teaching label

A **Source Teaching** is material organized from a supplied lecture, teaching guide, or note set. The public edition aims to preserve the source's internal terminology and relationships while making its boundaries explicit.

When a source makes scientific, medical, historical, or cultural claims that have not been independently established, The Way Home should say so rather than silently upgrading those claims into evidence.

## Source-note goals

For each major topic, document:
- origin and historical context
- primary or authoritative sources where available
- major traditions or schools of interpretation
- what is established evidence
- what is contested
- what is metaphysical or symbolic
- what comes directly from a supplied source teaching
- what is original synthesis within The Way Home
- what remains an open question
