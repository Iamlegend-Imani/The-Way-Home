# Lesson 07 — Where Is the Solar System Today?

**Label:** SOURCE TEACHING / FIELD NOTE METHOD

The supplied notes move from the birth chart to a second question:

> **Where is the Solar System today? Where is the collective currently?**

This turns NYOTA YAKO from a static birth-map framework into a dated practice of reading current planetary placements as collective weather.

## Why this should be a Field Note series

Current placements change. A page that says "Sun in Virgo" or "Moon in Sagittarius" will eventually become outdated.

For that reason, The Way Home treats this as a **method** rather than a permanent list of current positions.

Each collective-weather note should include:

- Date and timezone used for the chart.
- Current Sun sign.
- Current Moon sign.
- Mercury, Venus, Mars, Jupiter, Saturn, Uranus, Neptune, and Pluto placements.
- Interpretation using the NYOTA YAKO planetary functions.
- A clear separation between the actual astronomical/astrological placement and the symbolic interpretation layered onto it.

## Example structure from the supplied notes

The notes demonstrate the method with interpretations such as:

- Sun placement → how the collective is being seen / what is visible.
- Moon placement → collective feeling or private emotional tone.
- Mars placement → collective action and behavior.
- Mercury placement → communication and thought.
- Jupiter placement → where expansion is available.
- Venus placement → how love or support is expressed.
- Saturn placement → where rest, restriction, or usefulness is being negotiated.
- Uranus placement → "quantum jump" language within the source framework.
- Neptune placement → final-avatar / appearance language.
- Pluto placement → transformation.
