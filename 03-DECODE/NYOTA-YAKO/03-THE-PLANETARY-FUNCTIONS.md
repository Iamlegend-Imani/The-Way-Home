# Lesson 03 — The Planetary Functions

**Label:** SOURCE TEACHING / EXPLORATION

The source notes assign each planet a practical human function. These functions form the working vocabulary of NYOTA YAKO.

## The functions

| Planet | Function in the supplied notes |
| --- | --- |
| Mercury | Communication, thought, thinking for self, self-analysis |
| Venus | How to love; support, value, balance |
| Mars | How you behave and take action |
| Jupiter | Expansion, growth, level-up |
| Saturn | How you rest; usefulness, restriction |
| Uranus | "Quantum Jump"; higher octave of Mercury |
| Neptune | "Look of Final Avatar"; higher octave of Venus |
| Pluto | Transformation from final avatar to new creature; higher-octave transformation |

The notes also use Sun and Moon as foundational identity functions, even though they are not listed inside the section titled **7 Pillars**.

## Important unresolved point

The heading **7 Pillars** is followed by eight planetary functions: Mercury, Venus, Jupiter, Mars, Saturn, Uranus, Neptune, and Pluto.

Version 1 preserves this as an open question:

> **Which seven are intended to be the Seven Pillars?**

No planet is removed until the source teaching clarifies the count.

## Practice: function before sign

Before interpreting a placement, learn the function.

Example:

**Mercury = thought / communication.**  
Then ask: what does the sign containing Mercury add to that function within the source teaching?

Repeat for each planet.
