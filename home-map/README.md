# HOME//MAP

**A living map of self — a product of The Way Home.**

HOME//MAP is an interactive personal intelligence prototype for observing the relationships between body, mind, relationships, home, work, money, creation, purpose, spirit, community, nature, technology, cycles, memory and lived experience.

> Observe before interpreting. Reflect before believing.

## Privacy model for this prototype

This GitHub Pages version has no HOME//MAP backend. Profile information, check-ins, domain notes and journal entries are stored only in the current browser using `localStorage`. Data is not submitted to a HOME//MAP server.

The optional email field is therefore **not** an email-capture system yet. It is present only to test onboarding UX and future schema design.

## Interpretation rule

HOME//MAP can store cyclical or symbolic context, but the personal pattern layer must distinguish correlation from causation. The interface intentionally uses language such as “in your recorded observations” and identifies small sample sizes.

## Future production architecture (Vercel)

The static experience is intentionally structured so the UI can later move to a production application without redefining the product model.

Planned production layers:

1. **Identity** — secure authentication and account recovery.
2. **Personal data vault** — encrypted database, retention controls, export and deletion.
3. **Subscriptions** — paid HOME//MAP plans while The Way Home remains freely accessible.
4. **Astrology/cycle services** — birth chart, transits and ephemeris-grade calculations as optional context layers.
5. **Personal intelligence** — longitudinal pattern detection, semantic memory and “Ask My Life.”
6. **Integrations** — optional wearable/health, calendar and other user-authorized data sources.
7. **Consent architecture** — granular permissions for every sensitive data layer.
