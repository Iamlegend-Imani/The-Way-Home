# GitHub Pages Setup

The public site is designed to publish from the repository root.

After `site-v1` is merged into `main`, GitHub Pages should use:

- **Source:** Deploy from a branch
- **Branch:** `main`
- **Folder:** `/ (root)`

Expected project URL format:

`https://iamlegend-imani.github.io/The-Way-Home/`

The site uses only static HTML, CSS, JavaScript, and SVG. No build step is required.
