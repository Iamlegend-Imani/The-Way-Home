### Clarifying the 7–24–5 architecture

The current source set distinguishes three overlapping layers:

- **7 days:** the complete weekly self-support cycle.
- **24 hours:** the full-day inner atmosphere of feeling, self-love, information, and access.
- **5 planetary creation functions:** Mars, Mercury, Jupiter, Venus, and Saturn — the five functional tools after Moon/inner position and before Sun/renewed identity. "Active" does not mean constant exertion; Saturn's function includes structure, completion, preservation, restriction, and rest.
