# Gate IV — Navigate

## Learn to work with time, place, cycles, and relationship.

**Question:** How do time, place, cycles, and relationships affect me?

### Topics
- transits and planetary cycles
- lunar rhythms
- personal years and symbolic timing
- planetary days
- astrocartography
- relocation astrology
- synastry and composite charts
- attachment, projection, and relational patterns

### Gate principle

> **Use timing as a lens, not a command. Use place as information, not a guarantee.**

This Gate comes after Decode so learners understand the basic symbolic language before interpreting movement through time or geography.
