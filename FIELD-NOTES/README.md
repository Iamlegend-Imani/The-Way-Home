# Field Notes

Field Notes are where unfinished thinking is allowed to remain unfinished.

Use this section for:
- open questions
- personal observations
- evolving interpretations
- contradictions
- changed beliefs
- experiments and practices under review
- ideas that are not ready to become curriculum

A Field Note should not be presented as settled truth simply because it is meaningful.

## Suggested note header

- **Date:**
- **Question:**
- **Observation:**
- **Current interpretation:**
- **Knowledge lens:** EVIDENCE / TRADITION / EXPLORATION
- **What would change my mind:**
- **Next inquiry:**

The public evolution of understanding is part of The Way Home, not something to hide.
