# Library

The Library will hold the practical artifacts of The Way Home.

## Planned resource types
- teaching guides
- field guides
- workbooks
- maps
- journals
- practices
- printable worksheets
- essays
- glossaries
- reading lists

## First major artifact
### The Intuitive System
**The Body as a Map of Thought, Intuition, and Reality**

A 12-lesson teaching guide exploring a symbolic correspondence system involving memory, intuition, self-support, self-love, body symbolism, ancestry, planetary forces, and manifestation.

Before public release inside The Way Home, the guide will receive a public-safe editorial pass so symbolic and metaphysical claims remain clearly distinguished from medical, biological, and scientific evidence.
