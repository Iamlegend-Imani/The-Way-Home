# Versions

The Way Home is versioned because the work is expected to change.

Version history should record:
- new material
- corrections
- stronger sourcing
- changed interpretations
- retired claims
- renamed frameworks
- new downloads and practices

## Planned release structure

### v1.0 — The Beginning
The first coherent public map of the eight Gates, core methodology, initial source notes, and first downloadable resources.

Future versions should not erase earlier thinking without explanation. When understanding changes, document the change.

> **Evolution is part of the record.**
